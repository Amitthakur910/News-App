# 📰 News App

A modern and responsive News Application built using React.js that provides users with the latest news from various categories such as Business, Technology, Sports, Entertainment, Health, and Science. The app fetches real-time news data using a News API and displays articles in an easy-to-read format.

## 🚀 Features

* Latest news updates in real time
* Category-wise news filtering
* Responsive design for mobile and desktop
* Infinite scrolling or pagination support
* Search functionality
* Fast and user-friendly interface
* Article preview with image, title, description, and source
* Direct link to full news article

## 🛠️ Technologies Used

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3 / Bootstrap
* News API
* Axios / Fetch API

## ⚙️ Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project folder

```bash
cd news-app
```

3. Install dependencies

```bash
npm install
```

4. Create a `.env` file and add your API key

```env
REACT_APP_NEWS_API_KEY=your_api_key_here
```

5. Start the development server

```bash
npm start
```

The application will run at:

```bash
http://localhost:3000
```
